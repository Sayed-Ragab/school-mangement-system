School Management System

Developed a comprehensive school management system using Laravel to manage academic and administrative operations efficiently.

Built modules to manage students, teachers, parents, grades, exams, and attendance, ensuring organized data handling and streamlined workflows.

Implemented an accounting module to handle receipts and expenses, improving financial tracking and reporting.

Designed and enforced role-based access control (RBAC) for Admin, Teacher, Student, and Parent roles to ensure secure and controlled data access.

Technologies: PHP, Laravel, MySQL, JavaScript, AJAX, HTML, CSS

Project Setup Instructions
1- open cmd or terminal and write git clone https://github.com/Sayed-Ragab/school-mangement-system.git
2- copy .env.example to .env 
3- composer install
4- php artisan key:generate.
5- create database name in php myadmin and same name in .env file 
6- php artisan migrate --seed 
7- php artisan server
